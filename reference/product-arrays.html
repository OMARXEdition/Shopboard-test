Five methods. Five jobs.

MethodJobReturns
mapTransform every productNew array, same length for this dense catalog
filterKeep matching productsNew array, possibly empty
sortReorder productsThe same array, changed in place
findGet first matching productObject, or undefined
reduceCombine valuesAccumulated result

Shopboard examples

products.map(product => product.name)
products.filter(product => product.price < 150)
[...products].sort((a, b) => a.price - b.price)
products.find(product => product.id === 'magflow-station')
products.reduce((total, product) => total + Math.round(product.price * 100), 0) / 100

The last expression totals one of every catalog product. It is not the customer's cart total. A real cart needs product IDs and quantities; the current app stores only a count.

Use map when you need its returned array. Your existing forEach is appropriate for appending cards as a side effect. Use a numeric comparator with sort; copy the array first to preserve catalog order. These copies still share product objects, so do not change their properties accidentally.
