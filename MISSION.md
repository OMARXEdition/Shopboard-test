# Mission: JavaScript arrays in Shopboard

## Why

Learn to use map, filter, sort, find, and reduce to build product browsing and shopping features in Shopboard.

## Success looks like

- Choose the right array method for a product feature.
- Explain the callback and returned value.
- Filter and sort products without changing the original catalog order.
- Find a product by ID and calculate totals from product data.

## Constraints

- Use the existing vanilla JavaScript project and real product objects.
- Start with small examples and immediate feedback.

## Out of scope

No additional topics excluded by the user.
